## Shadcn Admin

The responsive application shell, navigation hierarchy, page spacing,
typography hierarchy, and panel treatment in Step 24 use
[Shadcn Admin](https://github.com/satnaing/shadcn-admin) as a visual and
interaction reference.

No Shadcn Admin source file was copied directly. The files under
`frontend/components/layout/` and `frontend/components/projects/` were
independently implemented for this repository's Next.js App Router and
generated API architecture. This notice is retained to make the design
influence and upstream license explicit.
